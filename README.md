#🐾 Pet Paradise – Pet Shop Webpage
A responsive and visually engaging pet shop website built using HTML, CSS, and JavaScript. This project showcases an online platform that provides services such as pet grooming, pet healthcare, and pet food delivery


🖼️ Preview


🗂️ Project Structure
pet_shop_webpage/
│
├── index1.html         # Main webpage (home)
├── login.html          # Login interface
├── styles1.css         # All styling
├── script.js           # Carousel or interactivity scripts
├── loginbg.jpg         # Background image for login
├── rew1.png - rew5.png # Review-related or product images
├── 7a18e3...jpg        # Banner or main image
└── README.md           # Project documentation
⚙️ How to Run

Clone this repo:
git clone https://github.com/sparrshaaa/pet_shop_webpage.git
cd pet_shop_webpage

Open the website:
Open index1.html in your preferred browser.
